# ✝️ نظام تسجيل حضور وغياب اجتماع كنيسة القديس الأنبا أنطونيوس بالـ QR

نظام متكامل واحترافي مخصص لكنيسة القديس العظيم الأنبا أنطونيوس لتسجيل ومتابعة حضور وغياب الخدام والمخدومين والشباب في الاجتماعات الأسبوعية ومدارس الأحد عبر مسح بطاقات الـ QR Code مباشرة باستخدام كاميرا اللابتوب أو الهاتف المحمول.

---

## 🚀 طريقة التشغيل السريعة:
1. انقر نقراً مزدوجاً (Double Click) على ملف:
   **`start.bat`** (أو `تشغيل_النظام.bat`)
2. سيبدأ الخادم المحلي بالعمل فوراً ويفتح النظام تلقائياً في متصفحك على: `http://localhost:8080/`.
3. (بديل مباشر): يمكنك النقر نقراً مزدوجاً على ملف **`index.html`** لفتحه في Google Chrome أو Microsoft Edge.

---

## 🌟 مميزات النظام الكنسي:

1. **⛪ هوية كنسية مباركة بصورة القديس الأنبا أنطونيوس:**
   - واجهة مخصصة تحمل اسم الكنيسة وأيقونة القديس العظيم الأنبا أنطونيوس كوكب البرية.
   - آية ترحيبية: «لأَنَّهُ حَيْثُمَا اجْتَمَعَ اثْنَانِ أَوْ ثَلاَثَةٌ بِاسْمِي فَهُنَاكَ أَكُونُ فِي وَسْطِهِمْ» (متى ١٨: ٢٠).

2. **📷 ماسح الـ QR المباشر للاجتماع:**
   - مسح سريع لبطاقة المخدوم أو الخادم عبر الكاميرا.
   - نغمة تنبيه صوتية فورية لتأكيد تسجيل الحضور.
   - **أوضاع مرنة:**
     - **تلقائي ذكي:** أول مسحة تسجل (حضور)، وثاني مسحة تسجل (انصراف عند نهاية الاجتماع).
     - **تسجيل حضور فقط.**
     - **تسجيل انصراف فقط.**
   - إمكانية البحث والمسح بالاسم أو المعرف في حال نسيان البطاقة.

3. **🪪 بطاقات حضور مميزة تحمل صورة القديس الأنبا أنطونيوس (Printable Badges):**
   - توليد بطاقات أنيقة لكل مخدوم وخادم تحتوي على صورة القديس الأنبا أنطونيوس، اسم العضو، أسرته أو مرحلته، ورقم المعرف، ورمز الـ QR.
   - زر **"طباعة جميع البطاقات (A4)"** ينسق البطاقات تلقائياً في شبكة جاهزة للطباعة والتوزيع.
   - إمكانية تنزيل رمز الـ QR كصورة فردية بصيغة PNG.

4. **👥 إدارة الخدام والمخدومين:**
   - تصنيف الأعضاء حسب الأسرة أو المرحلة (إعدادي، ثانوي، جامعيين، خريجين، اجتماع الخدام).
   - تحديد الصفة (مخدوم، مخدومة، خادم، خادمة، أمين خدمة، شماس، مرنم، أب كاهن).
   - تصدير بيانات المخدومين والخدام إلى ملف Excel.

5. **📋 كشوفات الحضور وتقارير الاجتماع:**
   - كشف تفصيلي بمواعيد الحضور والانصراف، ومن حضر مبكراً ومن تأخر عن بدء الاجتماع.
   - فلترة وتصفية حسب تاريخ الاجتماع أو المرحلة أو الأسرة.
   - **تصدير كشف الاجتماع إلى Excel (.xlsx / CSV)** متوافق مع اللغة العربية 100%.
   - طباعة كشف الاجتماع الورقي بضغطة واحدة.

6. **⚙️ إعدادات الاجتماع والتخزين:**
   - ضبط موعد بدء الاجتماع وحد التأخير (افتراضياً يبدأ 06:30 م وتأخير بعد 07:15 م).
   - تخزين محلي آمن في المتصفح مع إمكانية **تصدير نسخة احتياطية (JSON)** واسترجاعها في أي وقت.
